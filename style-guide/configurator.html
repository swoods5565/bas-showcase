3. Rooms

One row per room per unit. A room served by two units gets two rows, and both units light up when you hover it.

4. Object map Fill in once

Which object in each controller holds each value. Every unit of a type runs the same program, so this is set once per type and remembered in this browser. One COLUMN=OBJECT per line.

5. Floor plan areas

One area per line. Each becomes a page under Floor Plans with the color overlay turned on.

6. Download files

After importing

  1. Copy the files into the project at the paths shown. Merge the Buildings.csv row into the project's existing file if it has other buildings.
  2. In project.df5, set selectedTheme to the theme picked above.
  3. In Main.dg5, set alarmCounter to true.
  4. Draw the floor plan, equipment and summary pages in the designer, using the page names in the project CSV.
