Graphics Standard

How every ENTEC graphic looks and works, so a building built by any tech feels like the same product. Each section shows a working example first, then the rules.

Decided agreed and ready to build Proposed first suggestion, review it Open still to decide

Built in enteliVIZ

Pages use Delta's EWM "3dee" framework. Theme, nav and floor plan colors are settings files, not drawing.

Dark and light

Use the switch at the top. Every example on this page redraws in the theme you pick.

Delta colors stay

Alarm, override, normal, chart and piping colors are Delta standard in every theme.

Packages Decided

Packages differ by depth and features, never by which equipment gets graphics. Everything in the building gets a graphic in every package.

Canvas and grid

  • Decided Design every page at 1920 × 1080. enteliVIZ stretches pages to fit the screen, so this is the design size, not a fixed size.
  • Decided Snap everything to the 40 px grid.
  • Decided Dark theme background: the Nord dark grid image (nord-dark-grid-1920x1080.png).
  • Proposed Zones: 80 px header, 40 px outer margin, 400 px side columns.
  • The navigation menu opens over the page from the left. It never takes canvas space.

Navigation Decided

A left flyout. Pick a section, then pick a page from its panel. Pages in a panel sit under UPPERCASE headings. Try it:

    Rules

    • Sections, in this order: Floor Plans, Air Systems, Central Plant, Terminal Units, Miscellaneous, Dashboards, Alarms, Trends, Schedules, Reports, Legend.
    • Home is the header button, not a menu item.
    • Name sections by system, never "HVAC", "Ventilation" or "Hydronics".
    • Air Systems and Central Plant end with a SUMMARY heading. In Terminal Units, each unit type's summary table is its page, and single units open from the table.
    • Leave out sections the job doesn't have. enteliVIZ hides a section with no pages anyway.
    • Overrides is a report under Reports, not its own section.

    How it's built

    The building's project CSV drives the menu. The first row of a menu code names the section. A row whose name is UPPERCASE and has no page becomes a heading.

    Equipment pages Proposed

    • Info column on the left: Status, Setpoints, Alarms, in that order.
    • Graphic on the right. Air and water flow left to right.
    • Values sit next to the component they belong to, label above value.
    • Pipes use Delta piping colors. Ducts use the neutral accent.

    Summary tables Decided

    • Overridden values in Delta orange, alarms in Delta red.
    • Status and alarm columns are words, not just color.

    Master tag list Decided

    The tag prefix in a device name decides its equipment type and where it goes in the nav. The configurator uses this same list.

    enteliVIZ setup checklist

    What to change in a project so it matches this guide. The project configurator builds the CSV and theme files from an enteliWEB device list.

    1. Theme. Add Nord_Dark and Nord_Light to assets/CSV/CSS.json, set selectedTheme to Nord_Dark in project.df5.
    2. Navigation. Rebuild the building's project CSV with the sections and headings above.
    3. Floor plan colors. In assets/CSV/floorplanOverlays.json, the first overlay compares RM_T to RM_T_SP in °F with the zone colors. Set overlayEnabled to true on floor plan rows.
    4. Alarm badge. Set alarmCounter to true in Main.dg5.
    5. Draw in the designer: floor plans, zone tags, legend, key plan, equipment graphics, summary tables.
